# 🧩 Realite --- Minecraft RPG Platform

**Realite** --- модульная RPG-платформа для Minecraft (Paper),
построенная как набор взаимосвязанных плагинов, объединённых общим
ядром.

Проект ориентирован на:

-   долгосрочный прогресс игроков
-   глубокую RPG-логику (классы, эволюции, экономика, города, гильдии,
    квесты, предметы, магию)
-   масштабируемость без переписывания кода
-   чистую архитектуру и удобную разработку
-   единый CI и монорепозиторий

Репозиторий использует **монорепо-подход**: все плагины разрабатываются
и версионируются вместе.

------------------------------------------------------------------------

## 🧠 Архитектура проекта

    Realite/
    ├── RealiteCore/        # Ядро платформы (API/сервисы/интеграции)
    ├── plugins/            # Все игровые модули (плагины)
    │   ├── RealiteClasses/             # RPG-классы и прогрессия
    │   ├── RealiteChat/                # Форматирование чата и теги
    │   ├── RealiteGuilds/              # Гильдии игроков
    │   ├── RealiteCityInfrastructure/  # Городская инфраструктура
    │   ├── RealiteQuests/              # Квесты и лор
    │   ├── RealiteItems/               # Кастомные предметы и айтем-API
    │   └── RealiteMagic/               # Магия, заклинания и эффекты
    ├── build.gradle
    ├── settings.gradle
    └── README.md

### 🔑 Ключевая идея

-   **RealiteCore** --- единая точка входа, API и сервисы
-   игровые модули лежат в `plugins/*` и **не зависят друг от друга
    напрямую**
-   взаимодействие осуществляется через Core-API/сервисы
-   каждый модуль можно развивать независимо

## 🧱 Модули

### ⚙ RealiteCore

Ядро всей системы.

Функции:

-   сервисы и API (единая точка входа)
-   общие утилиты и контракты
-   интеграции (Vault, PlaceholderAPI и др.)
-   управление жизненным циклом модулей
-   единая модель локализации сообщений
-   базовые игровые контракты (Items, Magic, Quests, Guilds)

------------------------------------------------------------------------

### 🧬 plugins/RealiteClasses

Полноценная RPG-система классов.

Возможности:

-   выбор класса через GUI
-   XP и уровни
-   эволюции и ветки развития
-   пассивы и классовые эффекты
-   HUD / хотбар
-   GUI-настройки
-   интеграция с экономикой
-   события и хуки для квестов, магии, предметов, городов и гильдий

Конфигурация:

-   `classes.yml`
-   `xp.yml`

------------------------------------------------------------------------

### 🎒 plugins/RealiteItems

Система кастомных предметов и их поведения.

Возможности:

-   регистрация кастомных предметов через YAML
-   `CustomModelData`, glow, unstackable
-   локализованные имена и лор
-   привязка предметов к квестам, классам и магии
-   API для проверки и выдачи предметов
-   единый формат айтемов для всех модулей

Конфигурация:

-   `items/*.yml`
-   `items_locale.yml`

------------------------------------------------------------------------

### ✨ plugins/RealiteMagic

Модуль магии и заклинаний.

Возможности:

-   система заклинаний (spells)
-   кулдауны и стоимость
-   привязка к классам и эволюциям
-   условия использования
-   эффекты (частицы, урон, бафы, дебафы)
-   GUI-выбор заклинаний для игроков
-   команды для администраторов
-   полная интеграция с RealiteItems и RealiteClasses

Конфигурация:

-   `spells/*.yml`
-   `magic.yml`

------------------------------------------------------------------------

### 💬 plugins/RealiteChat

Форматирование игрового чата, префиксы и теги.

Возможности:

-   глобальный чат
-   гильдейский чат
-   режим **guild spy**
-   hover-подсказки для классов и гильдий
-   полная локализация сообщений

------------------------------------------------------------------------

### 🛡 plugins/RealiteGuilds

Система гильдий игроков.

Возможности:

-   создание и управление гильдиями
-   ранги и права
-   гильдейский чат
-   прогрессия гильдии
-   начисление XP
-   подготовка под казну и квестовую интеграцию

------------------------------------------------------------------------

### 📜 plugins/RealiteQuests

MVP-система квестов и лора.

Реализовано:

-   YAML-конфигурации квестов
-   цели: сбор, крафт, убийства, блоки, NPC
-   жизненный цикл квеста
-   локализация
-   хуки для классов, гильдий, магии и предметов

------------------------------------------------------------------------

### 🏙 plugins/RealiteCityInfrastructure

Городская инфраструктура.

Возможности:

-   города и регионы
-   участки и типы
-   магазины и рынок
-   контроль доступа
-   сделки и телепорты

``` bash
./gradlew build
```

    /plugins/**/build/libs/

------------------------------------------------------------------------

## 🚀 Быстрый старт

1.  Установите **Java 21** и **Paper**.
2.  Склонируйте репозиторий и выполните сборку:

``` bash
./gradlew build
```

3.  Скопируйте нужные `.jar` файлы в папку `plugins/` сервера.
