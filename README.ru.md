# 🧩 Realite — Minecraft RPG Platform

**Realite** — модульная RPG‑платформа для Minecraft (**Paper**), построенная как набор
взаимосвязанных плагинов, объединённых общим ядром (**RealiteCore**).

Проект ориентирован на:

- долгосрочный прогресс игроков
- глубокие RPG‑системы (классы, эволюции, экономика, города, гильдии, квесты, предметы, магия)
- масштабируемость без бесконечных переписок
- чистую архитектуру и удобство разработки
- монорепозиторий (все модули развиваются и версионируются вместе)

---

## 🧠 Архитектура проекта

```
Realite/
├── RealiteCore/                        # Ядро платформы (API / сервисы / мосты)
└── plugins/
    ├── RealiteClasses/                 # Классы, эволюции, мастерство (хуки интеграций)
    ├── RealiteChat/                    # Форматирование чата + мост гильдчата
    ├── RealiteGuilds/                  # Гильдии, ранги, прогрессия, бонусы
    ├── RealiteCityInfrastructure/      # Города, участки, магазины, рынок, правила регионов
    ├── RealiteQuests/                  # Движок квестов + контент‑паки
    ├── RealiteItems/                   # Кастомные предметы + Items API/Bridge
    ├── RealiteMagic/                   # Магия: касты, школы, реагенты, HUD
    ├── RealiteUI/                      # UI: Единое форматирование HUD, ActionBar, BossBar
    ├── RealiteFamiliars/               # Компаньоны и боевые питомцы
    ├── RealiteModels/                  # Кастомные модели сущностей
```

### 🔑 Ключевая идея

- **RealiteCore** — единый источник правды (API, общие сервисы, контракты мостов)
- модули **не должны** зависеть друг от друга напрямую
- интеграции делаются через **bridges/interfaces**, предоставляемые Core (или API модуля)
- модули можно добавлять/убирать и развивать независимо

## ✨ Что уже есть в геймплее

> Realite развивается поэтапно — цель: целостная расширяемая RPG‑экосистема, а не набор разрозненных плагинов.

### 🧬 Классы и прогресс (RealiteClasses)
- выбор класса через GUI
- XP/уровни и правила прогрессии
- эволюции / ветвления
- модификаторы мастерства и баланс‑хуки
- интеграции под магию, предметы, квесты, гильдии

### 🎒 Кастомные предметы (RealiteItems)
Централизованный провайдер предметов для всей платформы.

- YAML‑реестр предметов (стабильные itemId)
- поддержка:
  - `material`
  - `customModelData`
  - ключи локализации для названия и лора
  - glow
  - unstackable предметы
- строгая идентификация (серверная, не «по имени в чате»)
- публичная интеграция через `ItemsBridge`

### 🔮 Магия и спеллы (RealiteMagic)
Система магии, рассчитанная на расширение и баланс.

- реестр спеллов (YAML‑описания)
- проверки каста:
  - права
  - кд (глобальное + на спелл)
  - мана‑стоимость
  - посох/фокус (опционально)
  - реагенты (опционально)
  - стоимость в экономике (опционально)
  - региональные правила (запрет/разрешение + модификаторы)
- таргетинг и доставка:
  - self / entity / block / location
  - instant, AOE, chain (в зависимости от спелла)
- пайплайн эффектов (реестр executors)
  - эффекты подключаемые по типу (например particles/knockback/potions/etc.)
- HUD‑фидбек успех/фейл + диагностика (логирование кастов)
- безопасные smoke‑tests (опционально, для дебага)
- GUI выбора спеллов и требования фокуса
- Интеграции: Classes, Items, Economy, Regions, Guilds

### 🗺️ Квесты (RealiteQuests)
- YAML‑движок квестов с чёткой схемой и валидацией
- типы квестов:
  - глобальные
  - классовые
  - гильдийские
  - городские
  - скрытые (эволюции / условия)
- цели (objectives):
  - сбор предметов
  - убийства сущностей
  - использование предметов
  - касты магии
  - прогресс мастерства / классов
  - условия регионов и городов
- триггеры старта:
  - ручной
  - вход в регион
  - получение класса / эволюции
  - события от других модулей
- награды:
  - предметы
  - валюта
  - опыт
  - открытие классов / эволюций / спеллов
- GUI‑интерфейс отслеживания прогресса
- интеграции:
  - RealiteClasses (классы, эволюции, скрытые условия)
  - RealiteMagic (касты, мастерство, события магии)
  - RealiteItems (награды и требования)
  - RealiteGuilds (гильдийские квесты)
  - RealiteCityInfrastructure (городские и региональные условия)

### 🏰 Гильдии (RealiteGuilds)
- создание и управление гильдиями
- ранги, права и иерархия
- гильдийный чат (через RealiteChat bridge)
- прогрессия гильдии
- бонусы и хуки под классы, магию и экономику
- интеграции:
  - RealiteChat
  - RealiteClasses
  - RealiteQuests
  - RealiteCityInfrastructure

### 🏙️ Города и региональная инфраструктура (RealiteCityInfrastructure)
- система городов как игровых сущностей
- городские участки (plots):
  - покупка и аренда
  - владение игроками или гильдиями
  - типы участков (жилые, торговые, специальные)
- магазины и торговые зоны
- городская экономика:
  - налоги
  - регулярные сборы
  - содержание участков
- региональные правила:
  - разрешение / запрет магии
  - модификаторы урона и эффектов
  - PvE / PvP-ограничения
- хуки баланса для других модулей

Интеграции:
- RealiteGuilds — владение городами и участками гильдиями
- RealiteQuests — городские и региональные квесты
- RealiteMagic — региональные правила кастов и модификаторы магии
- RealiteItems — торговля, магазины, награды
- RealiteCore — единый доступ к данным регионов

Назначение:
- сделать города частью RPG-прогрессии
- связать территорию, экономику и геймплей
- заменить legacy-решения (WorldGuard-подобные) на RPG-логику

### 💬 Чат и коммуникация (RealiteChat)
Система чата вынесена в отдельный модуль и используется всей платформой.

- форматирование сообщений через **Kyori Adventure**
- единый пайплайн сообщений (без legacy ChatColor)
- гильдийский чат через bridge (интеграция с RealiteGuilds)
- префиксы:
  - класс
  - ранг гильдии
  - кастомные теги
- hover‑подсказки и кликабельные элементы
- возможность перехвата сообщений другими модулями (квесты, магия, события)

Интеграции:
- **RealiteGuilds** — гильдчат, spy‑режим, ранги
- **RealiteClasses** — отображение класса игрока
- **RealiteCore** — централизованная доставка сообщений

Назначение:
- убрать дублирование логики чата из геймплей‑плагинов
- обеспечить единый стиль сообщений для всей RPG‑экосистемы

### 🖥️ UI и HUD система (RealiteUI)

RealiteUI — централизованный UI-модуль платформы Realite, отвечающий за отображение
HUD, ActionBar, BossBar и экранных интерфейсов.

RealiteUI полностью отделяет визуализацию от геймплей-логики и выступает
единой точкой рендеринга UI для всех модулей.

Ключевые принципы:
- единый UI-пайплайн для всей платформы
- строгая граница между данными и отображением
- отсутствие прямого UI-кода в геймплей-плагинах

Архитектура:
- геймплей-модули (Classes, Magic, Quests, Guilds и др.) не рисуют UI напрямую
- модули передают структурированные данные через RealiteCore
- RealiteUI отвечает за:
  - layout
  - форматирование
  - пагинацию
  - обновление и рендеринг

Возможности:
- HUD-элементы (статы, мана, опыт, состояния)
- ActionBar и BossBar с унифицированным форматированием
- GUI-экраны с общей навигацией и пагинацией
- fallback-механизм для HUD (polling при недоступности событий)
- единая система локализации UI-текста
- расширяемые UI-providers для модулей

Интеграции:
- RealiteClasses — уровни, класс, прогресс
- RealiteMagic — мана, спеллы, касты, диагностика
- RealiteQuests — хаб квестов и детали прогресса
- RealiteGuilds — информация о гильдии
- RealiteCityInfrastructure — городские меню и участки
- RealiteCore — регистрация UI-провайдеров и доставка данных

Назначение:
- обеспечить единый визуальный стиль всей RPG-экосистемы
- упростить развитие и переработку UI без затрагивания логики
- сократить дублирование HUD-кода между модулями
- подготовить платформу к дальнейшему UI-масштабированию

### 🐾 Компаньоны и фамильяры (RealiteFamiliars)

- реальные боевые питомцы на базе ванильных мобов
- приручение через предмет (kill‑confirm)
- лимиты питомцев зависят от класса и уровня эволюции
- поддержка нескольких питомцев у игрока
- безопасные summon / dismiss / release
- прогрессия питомцев (уровни, роли, задел под таланты)
- полное управление через HUD и GUI (RealiteUI)
- PvE‑ориентированная логика (PvP — позже)
- интеграции:
  - RealiteItems (приручение, экипировка)
  - RealiteMagic (ауры, синергии)
  - RealiteClasses (лимиты, пассивы)
  - RealiteQuests (квесты на открытие и прокачку)
  - Города / Гильдии (лимиты)

### 🎭 Кастомные модели сущностей (RealiteModels)

- отдельный инфраструктурный плагин
- регистрирует `ModelsBridge` в RealiteCore
- применяет кастомные визуальные модели к сущностям
- использует ассеты из RealiteItems
- полностью опционален, с graceful‑fallback

## 🛠️ Сборка и разработка

### Требования

- Java **21**
- Gradle Wrapper (`./gradlew`)

### Сборка

```bash
./gradlew clean build
```
> Проверено на Java 21 и Paper 1.21.x

### Локальный запуск (Paper)

- собери нужные модули
- скопируй `.jar` в папку Paper `plugins/`
- запусти сервер, затем настрой модули в `plugins/<ModuleName>/`

## 🧭 Правила репозитория

- соблюдаем границы модулей (без прямых жёстких зависимостей между геймплей‑плагинами)
- для текста/сообщений используем **Kyori Adventure** (не legacy‑API)
- конфиги — YAML, в сообщениях используем ключи локализации вместо захардкода
- интеграции — через bridges (ItemsBridge, EconomyBridge, ClassesBridge и т.д.)
