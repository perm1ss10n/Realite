# 🧩 Realite — Minecraft RPG Platform

**Realite** — модульная RPG-платформа для Minecraft (Paper / Spigot), построенная как набор взаимосвязанных плагинов, объединённых общим ядром.

Проект ориентирован на:

* долгосрочный прогресс игроков
* глубокую RPG-логику (классы, эволюции, квесты, экономика)
* масштабируемость без переписывания кода
* удобную разработку и CI

Репозиторий использует **монорепо-подход**: все плагины разрабатываются и версионируются вместе.

---

## 🧠 Архитектура проекта

```
Realite/
├── RealiteCore/               # Ядро платформы
├── RealiteClasses/            # RPG-классы и прогрессия
├── RealiteQuests/             # Квесты и лор (WIP)
├── RealiteCityInfrastructure/ # Города и инфраструктура (planned)
├── plugins/                   # Сборка плагинов
├── build.gradle
├── settings.gradle
└── README.md
```

### 🔑 Ключевая идея

* **RealiteCore** — единая точка входа, API и сервисы
* Остальные плагины не зависят друг от друга напрямую
* Взаимодействие осуществляется через Core-API

---

## 🧱 Модули

### ⚙ RealiteCore

Ядро всей системы.

Функции:

* сервисы и API
* общие утилиты и контракты
* интеграции (Vault, PlaceholderAPI и т.д.)
* управление жизненным циклом модулей

---

### 🧬 RealiteClasses

Полноценная RPG-система классов.

Возможности:

* выбор класса
* XP и уровни
* эволюции и ветки развития
* классовые эффекты
* HUD / хотбар
* GUI-настройки
* интеграция с экономикой

Конфигурация:

* `classes.yml`
* `xp.yml`

---

### 📜 RealiteQuests (WIP)

Система квестов и лора.

Планируется:

* сюжетные и побочные квесты
* NPC
* привязка к классам и эволюциям
* диалоги
* награды и условия

---

### 🏙 RealiteCityInfrastructure (planned)

Городская и социальная инфраструктура.

Идеи:

* регионы и участки
* владение землёй
* дома и здания
* интеграция с экономикой и квестами

## 🔄 CI / Workflow

* единый CI для всего репозитория
* сборка каждого модуля
* защита ветки `main` через pull request
* разработка через feature-ветки

Пример:

```
feature/core-api
feature/classes-xp
fix/evolution-bug
```
