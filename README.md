# 🧩 Realite — Minecraft RPG Platform

**Realite** — модульная RPG-платформа для Minecraft (Paper), построенная как набор взаимосвязанных плагинов, объединённых общим ядром.

Проект ориентирован на:

- долгосрочный прогресс игроков  
- глубокую RPG-логику (классы, эволюции, экономика, города)  
- масштабируемость без переписывания кода  
- чистую архитектуру и удобную разработку  
- единый CI и монорепозиторий

Репозиторий использует **монорепо-подход**: все плагины разрабатываются и версионируются вместе.

## 🧠 Архитектура проекта

```
Realite/
├── RealiteCore/        # Ядро платформы (API/сервисы/интеграции)
├── plugins/            # Все игровые модули (плагины)
│   ├── RealiteClasses/             # RPG-классы и прогрессия
│   ├── RealiteChat/                # Форматирование чата и теги
│   ├── RealiteGuilds/              # Гильдии игроков
│   ├── RealiteCityInfrastructure/  # Городская инфраструктура (участки/магазины/рынок)
│   └── RealiteQuests/              # Квесты и лор (WIP)
├── build.gradle
├── settings.gradle
└── README.md
```

### 🔑 Ключевая идея

- **RealiteCore** — единая точка входа, API и сервисы
- игровые модули лежат в `plugins/*` и **не зависят друг от друга напрямую**
- взаимодействие осуществляется через Core-API/сервисы
- каждый модуль можно развивать независимо

### 💬 plugins/RealiteChat

Форматирование игрового чата, префиксы (LuckPerms) и классовые теги.

Пример конфигурации:

```yaml
language: "ru" # ru / en
chat:
  format: "{prefix}{class}{guild}{name}: {message}"
  tags:
    joiner: ""
  spaceBeforeName: true
  class-tag: "[Бродяга-I]"

prefix:
  enabled: true

class:
  enabled: true
  hover:
    enabled: true
  roman:
    enabled: true

guild:
  enabled: true
  hover:
    enabled: true
```

Примеры формата:

- `{prefix}{class}{guild}{name}: {message}` — формат по умолчанию.
- `{prefix}{class}[{guild}]{name}: {message}` — скобки вокруг гильдии только при наличии тега.
- `{prefix}{class}{guild} {name}: {message}` — пробел между тегами и именем (если `spaceBeforeName: false`).

Подсказки:

- `chat.tags.joiner` вставляется **между непустыми тегами** (например `" "` или `" | "`).
- Цвета можно задавать через `&`-коды в префиксах, `class-tag` и т.п.

Пример LuckPerms-команд для префиксов:

```
lp group default meta addprefix 100 "&7[Новичок]"
lp group vip meta addprefix 200 "&6[VIP]"
lp user Notch meta addprefix 300 "&b[LEGEND]"
```

Как включить/выключить hover:

```yaml
class:
  hover:
    enabled: true # выключить/включить hover для классов

guild:
  hover:
    enabled: false # выключить/включить hover для гильдий
```

### 🏙 plugins/RealiteCityInfrastructure

Городская и социальная инфраструктура: **участки, магазины и городской рынок**.

#### 🗺 City Areas (админ)
- выделение территории (через wand/selection)
- создание/удаление/список городских зон

#### 🧱 Plots (участки)
- участки с типами (например: `SHOP`, и другие — по конфигу)
- покупка свободного участка с проверкой лимитов и экономики
- список/инфо/поиск по `id` или `#number`
- ближайшие свободные участки в радиусе
- управление доступом: `member`, `trusted`
- сделки между игроками: **transfer** (передача) и **sell** (продажа) с подтверждением через `accept`
- освобождение участка `release` + (опционально) очистка участка через сервис очистки

#### 🛍 Shops (магазины на участках типа SHOP)
- ShopPoint (точка магазина) внутри SHOP-участка
- листинг магазина: `title`, `category`, `description`
- статус `open/close`
- команды: создать точку, настроить листинг, список точек на участке, инфо рядом, удалить точку

#### 🧾 Market (городской рынок)
- список последних/актуальных магазинов
- фильтр по категории, поиск по строке
- поиск ближайших магазинов
- инфо о магазине и телепорт к точке (`goto`)
- (опционально) телепорт в хаб рынка (`hub`) по конфигу
- (опционально) стоимость/кулдаун/права через MarketService

#### 🧮 Rent (аренда для SHOP, опционально)
- статус оплаты аренды и срок `paidUntil`
- оплата аренды на N периодов
- если аренда просрочена — (опционально) блокируется торговля/обновления листинга

#### 🏷 Markers (маркеры магазина)
- визуальные маркеры над точками магазина (ArmorStand)
- обновляются при изменении листинга
- отображение текста через **Adventure Component API** (без legacy `setCustomName(String)`)

Нововведения:

- сделки с участками через `transfer/sell` + подтверждение `accept`
- поиск ближайших свободных участков и магазинов
- телепорт к магазину через команду `goto`
- опциональная аренда SHOP-участков со статусом `paidUntil`

## 🔮 Планируемые модули

### 🐾 RealiteFamiliars (planned)

Система **боевых и вспомогательных питомцев**, привязанная к классам игроков.

Идея:

- игрок может **приручать определённых мобов** в зависимости от класса
- тип доступных питомцев зависит от класса и прогресса
- питомец — это полноценный игровой объект, а не просто косметика

Планируемые возможности:

- питомец может **атаковать врагов**
- питомец может **лечить игрока или союзников**
- питомец может **хранить предметы** (мобильное хранилище)
- поведение и способности зависят от:
  - типа моба
  - класса игрока
  - эволюции/прокачки
- интеграция с:
  - RealiteClasses
  - RealiteQuests
  - RealiteGuilds (гильдийные питомцы / усиления)

## 🚀 Быстрый старт

1. Установите **Java 21** и **Paper** сервер.
2. Склонируйте репозиторий и соберите проект:

   ```bash
   ./gradlew build
   ```

3. Скопируйте нужные плагины из:

   ```
   /plugins/**/build/libs/
   ```

4. Поместите `.jar` в папку `plugins/` вашего сервера Paper и запустите сервер.
